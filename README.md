# DERMIQT — Skincare UI Frontend Replication

A beginner-friendly, high-fidelity frontend replication of the **DERMIQT** skincare website design, built using **React**, **Vite**, and **Vanilla CSS**.

---

## Features & Design Highlights

1. **Visual Accuracy to Design Reference**:
   - **Hero Section**: Deep roast cocoa brown backdrop (`#462c21`), tilted diagonal capsule mask with skincare foam photography, rotating circular quality stamp badge (`PRODUCT FOR BEAUTY SKINCARE QUALITY`), avocado clarity badge (`CLEAR EXTRA OIL PRESERVE THE YOUTH`), yellow circular `Shop Now` button, and bottom 100% Organic banner.
   - **Pure Skincare Section**: Clean warm cream background (`#fdf9f5`), headline with inline visual preview strip and `SEE MORE >` link, soft peach card (`Ageless starts with care`) with Amber dropper bottle and `Pure Skincare` badge, plus the white card with `Lumière` script branding and dual artisan soap photos.
   - **Products Section**: "Your next favorite right here" with interactive hashtag filter pills (`#RealRadiin`, `#Skincare`, `#RealPure`, `#Beauty`) and 3 product cards (*Sun Beauty Oil*, *Exfoliator Gel*, *Rose Geranium*) with quick-add actions and prices.
   - **Soul Glow Split Section**: Radiant smiling portrait juxtaposed against the warm brown card with floral icon, "Skin glows when the soul does", 29% Net Discounts, Royal Product case study badge, "GET GLOWING" button, and sunflower graphics.
   - **Solutions Bento Section**: "Powerful skin solutions visible radiance", interactive "WATCH OUR STORIES" play button, science-backed hydration card, and 4-card bento grid (Rapid wrinkle repair cream, orange thirsty skin card, beauty begins with skincare, and daily facial moisturizer roller).
   - **Radiance Routine Section**: "Original Skincare Lotion" with 75% growth stat card, smiling man with green clay facial mask, "Wellness in Mind and Body" floating card, and "Routine is the root of radiance".

2. **Frontend Interactions**:
   - **Slide-In Shopping Bag Drawer**: Click "SHOP NOW" or "+ Quick Add" on any product to view your bag, modify quantities, remove items, or simulate checkout.
   - **Dropdown Navigation**: Interactive "PRODUCTS" menu on hover/click.
   - **Story & Routine Modal**: Interactive "WATCH OUR STORIES" video preview and "GET GLOWING" routine quiz modal.
   - **Toast Notifications**: Feedback toasts when products are added to the shopping bag.

## How to Run Locally

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```

### 3. Open in Browser
Visit the local URL shown in your terminal (usually [http://localhost:5173/](http://localhost:5173/)).
